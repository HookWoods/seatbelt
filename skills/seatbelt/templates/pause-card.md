# Pause card

Use exactly this shape, in the user's language. One pause per message.

```
⏸️ Pause: Secret key visible
What is happening: your Stripe key is in code anyone can see.
Risk if we continue: someone can make payments as you.
1️⃣ I make the code read it from a locked drawer (secret variables); you paste a new key there yourself, and I show you how (2 min, recommended)
2️⃣ Continue anyway, and I note the risk in your notebook
```

Rules:
- Title: five words or fewer.
- "What is happening" and "Risk if we continue": one sentence each, plain words, framed as cost, risk or time.
- Option 1 is the safe one and shows its cost. Option 2 is always "Continue anyway", translated into the user's language (for example "Continuer quand même").
- Keep the ⏸️ symbol and the 1️⃣ / 2️⃣ markers; translate every word.
